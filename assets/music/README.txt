Optional: put your own LICENSED background music here (mp3/wav/ogg/m4a).
A file whose name starts with a mood (playful, sneaky, bouncy, dramatic, chill) is used for scripts with that
mood; otherwise the first file is used. If this folder is empty, original music is synthesized for each video.
Only use music you have the rights to (e.g. YouTube Audio Library tracks you downloaded yourself).
